# Contributing
Thank you for considering a contribution.
1. Open or select a narrowly scoped issue before substantial work.
2. Use synthetic or public test data only.
3. Never commit personal evidence, credentials, private paths, or raw logs.
4. Keep the runtime dependency-free unless a change clearly requires otherwise.
5. Add or update tests and run `python -m unittest discover -s tests -v`.
6. Explain privacy and compatibility effects in the pull request.
Bug reports should include a minimal synthetic reproduction, Python version, operating system, expected result, and actual result.
