# Security Policy
Please do not open a public issue containing a vulnerability, a real evidence bundle, credentials, personal information, or sensitive filenames.
Until a dedicated private reporting channel is configured, report only that a private security contact is needed through a minimal GitHub issue that contains no exploit details or sensitive data. A maintainer will arrange a private channel.
The project does not claim that a plain SHA-256 manifest proves authorship, event time, or truthfulness. It detects byte changes relative to a previously created manifest.
